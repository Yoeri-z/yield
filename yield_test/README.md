# yield_test

Test helpers for the
[`yield_state`](https://pub.dev/packages/yield_state) package.

`yield_test` provides `testTransform`, `testAsyncTransform`, and `testFlow` —
concise test wrappers that match the `(State, Effect)` shape produced by
yield-state transforms. See the
[yield_state testing docs](https://pub.dev/packages/yield_state#testing) for
usage examples and API details.
